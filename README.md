# Поиск прокси-метрики для покупателя авто

## Описание задачи
Цель — найти **прокси-метрику**, которая хорошо коррелирует с фактом покупки автомобиля (`is_bought`) пользователем-искателем, чтобы без регулярных обзвонов оценивать эффективность платформы.

## Данные
Файл: **`proxy_metrics_homework.csv`**

| Поле                  | Описание |
|-----------------------|----------|
| `user_id`             | ID пользователя |
| `views`               | Суммарное количество просмотров объявлений за весь период активности |
| `contacts`            | Суммарное количество контактов (просмотры телефона, сообщения) |
| `last_7_views`        | Просмотры за 7 дней до ухода в отток |
| `last_3_views`        | Просмотры за 3 дня до ухода в отток |
| `last_7_contacts`     | Контакты за 7 дней до ухода в отток |
| `last_3_contacts`     | Контакты за 3 дня до ухода в отток |
| `live_days`           | Количество дней от первого появления в продукте до ухода в отток |
| `messages_events`     | Количество сообщений, отправленных искателем |
| `add_to_favor_events` | Количество добавленных в избранное объявлений |
| `max_views_delta`     | Разница между минимальным ненулевым и максимальным количеством просмотров в день |
| `is_bought`           | Факт покупки авто (1 — купил, 0 — нет) |

---

## Методология
1. **Разведочный анализ (EDA)**  
   - Проверка распределений метрик у покупателей и непокупателей.  
   - Статистические тесты для выявления значимых различий.  
   - Корреляционный анализ с целевой переменной.

2. **Трансформации метрик**  
   - Логарифмирование признаков для учета нелинейных зависимостей.  
   - Поиск пороговых значений для максимизации корреляции бинарных метрик.

3. **Отбор кандидатов**  
   - Сравнение метрик по силе корреляции и значимости (p-value).  
   - Выбор наиболее устойчивых и интерпретируемых признаков.

---

## Результаты анализа
- **Суммарные контакты (`contacts`)** — высокая значимость и корреляция с фактом покупки. Логарифмирование усилило связь.
- **Контакты за 3 дня до оттока (`last_3_contacts`)** — лучший кандидат в качестве прокси-метрики.  
  - Наибольшая корреляция достигается при **пороге ≥ 3 контактов**.
- **Просмотры за последние дни (`last_3_views`, `last_7_views`)** — также показывают заметную зависимость, особенно в логарифмированном виде.
- **Live days (`live_days`)** — влияет на вероятность покупки, но корреляция недостаточна для использования как единственной метрики.

---

## Вывод
Наилучшей прокси-метрикой для оценки доли покупателей без проведения обзвонов является:
> **Количество контактов за последние 3 дня до ухода в отток (≥ 3)**

Эта метрика демонстрирует наибольшую корреляцию с фактом покупки и хорошо отражает намерение пользователя завершить сделку.
