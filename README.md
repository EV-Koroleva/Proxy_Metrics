# Proxy Metrics for Car Buyers

## Описание проекта
Цель проекта - найти **прокси-метрику**, которая хорошо коррелирует с фактом покупки автомобиля искателем (покупателем) через классифайд.

---

## Данные
Файл: `proxy_metrics.csv`  

**Описание признаков:**
- `user_id` — ID пользователя  
- `views` — суммарное количество просмотров объявлений  
- `contacts` — суммарное количество контактов (просмотры телефона + сообщения)  
- `last_7_views` — просмотры за 7 дней до ухода в отток  
- `last_3_views` — просмотры за 3 дня до ухода в отток  
- `last_7_contacts` — контакты за 7 дней до ухода в отток  
- `last_3_contacts` — контакты за 3 дня до ухода в отток  
- `live_days` — длительность (в днях) с первого появления пользователя до ухода в отток  
- `messages_events` — количество написанных сообщений  
- `add_to_favor_events` — количество добавлений в избранное  
- `max_views_delta` — разница между самым малоактивным (но ненулевым) и самым активным днём по просмотрам  
- `is_bought` — целевая переменная (факт покупки авто через классифайд, собран по обзвону)  

**Критерии отбора пользователей:**
- активные искатели, ушедшие в отток (нет активности >7 дней)  
- отсутствие активных объявлений за последние 3 месяца (исключены листеры)

---

## Методология
1. **Сбор данных**  
   - Команда обзванивала пользователей, чтобы определить целевую переменную `is_bought`.  
   - Были отобраны только искатели, а не листеры.  

2. **Предобработка данных**  
   - Проверка на пропуски, выбросы, распределения признаков.  
   - Приведение данных к удобному формату анализа.  

3. **Формирование гипотез**  
   - Метрики активности (`views`, `contacts`, `messages_events`) могут коррелировать с фактом покупки.  
   - Недавняя активность (`last_7_views`, `last_3_contacts`) потенциально сильнее связана с фактом покупки, чем общая активность.  
   - Социальные действия (`add_to_favor_events`) могут указывать на серьёзность намерений.  

4. **Анализ корреляций и статистики**  
   - Построение матрицы корреляций.  
   - Проверка значимости метрик через тесты (хи-квадрат, t-test, регрессии).  

5. **Оценка качества прокси-метрик**  
   - ROC-AUC и Precision-Recall для выбранных метрик.  
   - Интерпретация и бизнес-ценность.

---

## Анализ
- Метрики просмотров (`views`, `last_7_views`) показывают корреляцию с покупкой, но менее выразительную, чем контакты.  
- Метрики взаимодействия (`contacts`, `last_7_contacts`, `messages_events`) оказываются более сильным предиктором.  
- Добавления в избранное (`add_to_favor_events`) могут служить дополнительным индикатором вовлечённости.  
- Метрика `max_views_delta` даёт слабый сигнал, так как отражает скорее стиль потребления контента, чем факт покупки.

## Выводы
- **Главный вывод:** наиболее сильная прокси-метрика для факта покупки — **количество контактов (`contacts`)**, особенно в последние дни перед уходом (`last_7_contacts`, `last_3_contacts`).  
- Метрика **сообщений (`messages_events`)** также хорошо подходит как прокси.  
- Для мониторинга эффективности можно использовать комбинацию:  
  `contacts + messages_events`  
- Такой набор метрик позволяет косвенно отслеживать покупки без регулярных обзвонов.
